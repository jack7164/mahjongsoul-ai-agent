# 安裝說明

整個安裝只需要手動做三件事：**下載程式**、**安裝 Docker Desktop**、**放入 Mortal 權重**。
其餘（Python、辨識套件、Mortal 映像）都由 `打包主程式.bat` 與 `雀魂AI助手.exe` 自動完成。

## 系統需求

| 項目 | 需求 |
|---|---|
| 作業系統 | Windows 10 / 11（64 位元） |
| 顯示卡 | NVIDIA（強烈建議）。沒有也能裝，但辨識速度跟不上牌局 |
| 記憶體 | 16 GB 以上 |
| 硬碟 | 約 15 GB 剩餘空間 |
| 網路 | 第一次安裝時需要（下載約 3 GB 套件與 Docker 映像） |

## 1. 下載程式

**方法 A：下載 ZIP（一般使用者）**

1. 登入 GitHub，打開本專案頁面（私人 repo，需要被加為協作者才看得到）。
2. 按綠色的 **Code → Download ZIP**。
3. 解壓縮到一個**路徑短、沒有特殊符號**的資料夾，例如 `D:\MIA`。
   - 不要放在「下載」資料夾裡直接執行，也不要放在 OneDrive 同步的資料夾（大量小檔會一直同步）。

**方法 B：git clone（開發者）**

```bat
git clone https://github.com/<帳號>/<repo>.git D:\MIA
```

## 2. Docker Desktop

Mortal 需要 Linux 環境，所以放在 Docker 裡執行。Docker Desktop 無法用程式自動安裝，要手動裝一次：

1. **開啟 WSL 2**：在「開始」搜尋 PowerShell → 右鍵「以系統管理員身分執行」→ 輸入

   ```powershell
   wsl --install
   ```

   完成後重新開機。
2. **安裝 Docker Desktop**：<https://docs.docker.com/desktop/setup/install/windows-install/>
   安裝時保持勾選「Use WSL 2 instead of Hyper-V」（預設），裝完重新開機。
3. **打開 Docker Desktop**，等左下角顯示綠色的「Engine running」。第一次開啟會要求同意條款，可以略過登入。
4. 建議到 Settings → General 勾選「Start Docker Desktop when you sign in」，之後開機就會自動開啟。

> `雀魂AI助手.exe` 的安裝精靈在 Docker 這一列也有「安裝步驟」按鈕，內容和上面相同。

## 3. Mortal 權重

`mortal.pth`（約 130 MB）超過 GitHub 單檔 100 MB 的上限，所以不在 repo 的檔案裡，要另外下載：

1. 在專案頁面右側點 **Releases**，下載最新版本附件裡的 `mortal.pth`。
2. 放到 `app\Model\mortal.pth`（和 `region_model_best.pt` 等檔案放在一起）。

沒有放的話，安裝精靈的「Mortal 權重檔」一列會顯示「缺少」，並提供「開啟資料夾」按鈕；放好後按「重新偵測」即可。

> 進階：如果權重放在可以直接下載的公開網址，把網址填進 `config.json` 的 `"mortal_weights_url"`，
> 安裝精靈發現缺少權重時就會自動下載。私人 repo 的 Release 需要登入才能下載，所以這個方式不適用。

## 4. 第一次執行

雙擊 **`打包主程式.bat`**。它會：

1. **準備 Python**：
   - 電腦上已經有 `runtime\python\`（之前裝過）或 conda 環境 `mahjongsoul_agent`／`mjai`，就直接用。
   - 都沒有的話，自動下載安裝工具 [uv](https://github.com/astral-sh/uv) 和獨立的 Python 3.10，放在 `runtime\`（約 30 MB，不需要另外裝 Anaconda）。
2. **打包**：安裝 PyInstaller，把 `launcher\launcher.py` 打包成 `雀魂AI助手.exe`（約 11 MB）。
3. **開啟** `雀魂AI助手.exe`，進入安裝精靈。

> 之後每次使用直接雙擊 `雀魂AI助手.exe` 就好，不用再執行 `打包主程式.bat`。
> 只有更新程式後（`launcher\launcher.py` 有改）才需要重新打包。

## 5. 安裝精靈的五個項目

`雀魂AI助手.exe` 第一次開啟時會逐項檢查，缺少的會自動安裝。全部完成後，之後開啟會直接跳過這一頁。

| 項目 | 內容 | 時間 |
|---|---|---|
| 系統檢查 | Windows 版本、NVIDIA 顯示卡、記憶體、剩餘空間 | 幾秒 |
| Python 環境與辨識套件 | 依有無 NVIDIA 顯示卡安裝 GPU 版或 CPU 版（torch 2.5.1、ultralytics 8.4.127，版本鎖定），裝在 `runtime\` | 約 10–30 分鐘（下載約 3 GB） |
| Docker Desktop | 檢查有沒有安裝、有沒有開啟 | 幾秒 |
| Mortal 權重檔 | 檢查 `app\Model\mortal.pth` | 幾秒 |
| 建立 Mortal 映像 | 用 `app\Mortal\` 的原始碼建立 Docker 映像 `mortal` | 約 10–30 分鐘（只需一次） |

- 安裝期間可以關掉視窗，下次開啟會接著做。
- 「顯示詳細紀錄」可以看到每一步的輸出；失敗時有「重試」按鈕。
- ★ **不要自己升級 ultralytics**：不同版本對同一個模型的推論方式不同，辨識結果會改變（2026-11-03 實測）。

## 6. 更新到新版

1. 下載新版 ZIP，解壓縮後**覆蓋**到原本的資料夾（保留 `runtime\`、`紀錄\`、`app\Model\mortal.pth`、`config.json`）。
2. 如果[版本紀錄](../CHANGELOG.md)寫到啟動器有改，重新執行一次 `打包主程式.bat`。
3. 如果版本紀錄寫到 `requirements_*.txt` 有改，刪掉 `runtime\env.json`，開啟 `雀魂AI助手.exe` 會重新檢查並補裝套件。

## 7. 解除安裝

1. 刪掉整個程式資料夾（包含 `runtime\`、`紀錄\`）。
2. 刪掉 Mortal 映像：在命令提示字元輸入 `docker image rm mortal`。
3. 不再需要 Docker 的話，從「設定 → 應用程式」解除安裝 Docker Desktop。

若曾用「網頁版＋Chrome」且程式沒有正常結束，Chrome 的兩個暫時設定可能還在。
先開一次 `雀魂AI助手.exe`（開啟時會自動還原），再刪除資料夾。可以在 Chrome 網址列輸入 `chrome://policy` 確認已清空。

## 8. 手動安裝（開發者）

不用安裝精靈，自己建環境：

```bat
:: 1. Python 3.10 環境（conda 或 uv 皆可）
conda create -n mahjongsoul_agent python=3.10 -y
conda activate mahjongsoul_agent

:: 2. 辨識套件（有 NVIDIA 顯示卡用 gpu，沒有用 cpu）
pip install -r requirements_gpu.txt

:: 3. Mortal 映像（Docker Desktop 要先開著，mortal.pth 要先放好）
cd app\Mortal
docker build -t mortal:latest .
cd ..\..

:: 4. 直接啟動主程式（不經過啟動器）
set PYTHONIOENCODING=utf-8
python app\live_v7\agent.py

:: 或啟動「啟動器」的原始碼
python launcher\launcher.py
```

啟動器會自動找到名為 `mahjongsoul_agent` 或 `mjai` 的 conda 環境，驗證通過就直接使用，不會重裝。
