## 1. 開始一場

1. 打開 **Docker Desktop**（已設定開機自動開啟就不用）。
2. 打開雀魂：
   - **Steam／桌面版**：視窗比例要是 16:9（例如 1920×1080、1600×900、1280×720），不能最小化；被別的視窗蓋住沒關係。
   - **網頁版**：先不用開，程式會幫你用 Chrome 開（見[第 5 節](#5-網頁版注意事項)）。
3. 雙擊 **`雀魂AI助手.exe`**，依序經過：

   | 頁面 | 做什麼 |
   |---|---|
   | 說明 | 用途、運作方式、風險、需要的權限、免責聲明。勾選「我已閱讀」後按「同意並繼續」（同意後下次不再出現） |
   | 平台 | 選「Steam／桌面版」或「網頁版」；網頁版再選「Chrome（建議）」或「其他瀏覽器」 |
   | 畫面確認 | 允許擷取視窗後，會顯示程式實際看到的畫面；確認是牌桌畫面後按開始 |

4. 開始後，螢幕最上方出現**字幕列**，啟動器視窗縮到工作列。
   字幕列可以用滑鼠按住文字拖動，建議放在遊戲畫面上方、不擋到牌的地方。
5. 字幕顯示「就緒，等待對局開始…」後開始打牌，程式會自己偵測到對局開始。

> ★ 程式只能「建議」，實際打哪張還是你自己決定。辨識偶爾會錯，建議看起來怪怪的時候以自己為準。

## 2. 字幕列

```
┌──────────────┬────────────────────────────────────────┬──────────┐
│ GPU · 9.8 fps │ 建議：立直，打 2m　　次選：不立直，打 2p │ [－][↻][■] │
│ 東2局 0本場    │                                        │          │
└──────────────┴────────────────────────────────────────┴──────────┘
```

**左邊**：GPU／CPU、每秒處理幾幀（GPU 正常約 8–15 fps）、目前第幾局。重新同步過會標「（已重新同步）」；遊戲畫面太小時改成橘色「⚠ 畫面太小」。

**中間（字幕）**：

| 顏色 | 內容 | 說明 |
|---|---|---|
| 白色 | 啟動中／載入辨識模型中… | 約 10–30 秒 |
| 淺藍色 | 就緒，等待對局開始… | 準備好了，開局後自動開始 |
| 綠色 | 開始辨識、東2局 開始 | 顯示 2–3 秒 |
| 白色粗字 | 建議：打 北　次選：打 9s | 一般打牌建議 |
| **金色粗字** | 建議：碰 5p（用 5p 5p）　次選：不鳴<br>建議：立直，打 2m　次選：不立直，打 2p | 要你按宣告鍵（吃／碰／槓／立直／和了），整條變金色 |
| 淺藍色 | 本局結束：對家榮和（你放銃）　等待下一局… | 偵測到和了／流局，下一局自動接上 |
| 橘色 | 辨識有誤，下次輪到你摸牌時自動重新同步 | 見下方說明 |
| 紅色 | 錯誤（Docker 沒開、找不到遊戲視窗…） | 照字幕說的處理，程式會自己再試 |

**右邊**：三個按鈕 **[－]** 縮小、**[↻]** 新的一場、**[■]** 停止。

**建議什麼時候消失**：你做了動作（打牌、鳴牌…）之後，或換局時。「不鳴」顯示 4 秒後自動消失。

**橘色「辨識有誤」是什麼**：程式算的「你的手牌」跟畫面對不上（例如讀錯一張牌）。

- 下次輪到你摸牌時，程式會照當下畫面重建這一局，建議自動恢復，不用按任何東西。
- 別家的牌讀錯、漏看一個動作時，程式直接略過那一筆，建議照常，不會出現這行字（只記在 `console.log`）。
- 重新同步後 Mortal 不知道別家每張牌確切是哪一巡打的，安全牌判斷可能稍微不準；你的手牌、寶牌、牌河都是對的。

## 3. 手牌數字徽章

| 徽章 | 意思 |
|---|---|
| 綠色「1」 | 建議打的那張（要打剛摸到的那張時，就標在摸入牌上） |
| 深色「2」 | 次選那張（次選是「不鳴」「立直」之類時沒有） |
| 金色「碰／吃／槓」 | 建議鳴牌時，標在要拿出來的那幾張 |

- 徽章不會擋到滑鼠，可以直接點下面的牌；遊戲視窗移動後會立刻跟上。
- **立直**：「1」標在立直要打的那張。先按遊戲的「立直」，再點「1」那張。
- **和了**：只有字幕（金色「建議：和了！」），按遊戲的「和」／「自摸」。
- **不鳴**：只有字幕，按遊戲的「跳過」。

## 4. 快捷鍵

遊戲視窗在前面時也有效。

| 鍵 | 功能 |
|---|---|
| **F8** | 字幕列縮小／展開。縮小後剩一個小膠囊「● AI ▾」，點它也會展開；要宣告時直接寫動作，例如「● 碰! ▾」 |
| **F9** | 手牌徽章顯示／隱藏 |
| **F7** | 次選顯示／隱藏（字幕的「次選 …」和「2」徽章一起） |

想換鍵：修改 `config.json` 的 `"hotkeys"`（F1–F12，可加 `Ctrl+`／`Alt+`／`Shift+`，例如 `"Ctrl+Alt+F8"`）。
被別的程式佔用而註冊失敗時，`console.log` 會記錄。

## 5. 網頁版注意事項

**選「Chrome（建議）」時**，程式會：

1. 檢查 Chrome 有沒有開著；開著的話會請你先關掉（參數要在 Chrome 重新開啟時才生效）。
2. 暫時改兩個 Chrome 設定：雀魂分頁不會被「記憶體節省模式」卸載、關閉「節能模式」。
   這段期間 Chrome 設定頁會顯示「由貴機構管理」，是正常的。
3. 用特殊參數開啟 Chrome 直接進雀魂：視窗被別的視窗整個蓋住也會照常更新畫面。
4. 按字幕列 [■] 停止時，第 2 步的設定自動還原成你原本的樣子（Chrome 本身不會被關掉）。

程式沒有正常結束的話，下次開啟 `雀魂AI助手.exe` 時會先自動還原。想確認狀態：Chrome 網址列輸入 `chrome://policy`。

**其他瀏覽器**：只擷取畫面，不調整瀏覽器設定；視窗被完全蓋住時畫面可能停住。

**共通注意事項**：

- 遊戲畫面寬度至少 **1100 像素**（最大化最穩）。視窗縮太小牌會讀錯，字幕列左邊會出現橘色警告，拉大就好。
- 全螢幕（F11）、一般視窗、最大化都可以；網頁縮放幾 % 都可以（建議 100%）。程式會自己在瀏覽器裡找出遊戲畫面。
- 要先進到牌桌畫面才找得到遊戲區域。
- 雀魂要是那個瀏覽器視窗「目前顯示的分頁」，而且瀏覽器不能最小化。
- 不要同時開著 Steam 版跟網頁版，程式可能分不出要抓哪一個。
- 雀魂網址在 `config.json` 的 `"web_url"`（預設 `https://game.maj-soul.com/1/`）。

## 6. 一場打完之後

「一場」是整個東風戰（打到東4局結束）或半莊戰（打到南4局結束）。一場裡面的換局（和了、自摸、流局）程式會自己處理。

一場結束後，開下一場之前請擇一：

- 按字幕列 **[↻] 新的一場**：存好這一場的紀錄、開新的紀錄資料夾、重新載入（約 10–30 秒），看到「就緒」再開下一場。
- 按 **[■] 停止**：存好紀錄、關掉 Mortal；啟動器顯示「已結束」，可以按「再開一場」或「關閉」。

> ★ 不要不按就直接連打下一場：Mortal 的座位編號整場固定，接著打下一場可能會錯位。
> ★ 不要直接關掉程式視窗：紀錄可能來不及寫完。

## 7. 紀錄

每次開始（或按「新的一場」）會建立一個資料夾 `紀錄\<日期_時間>\`：

| 檔案 | 內容 |
|---|---|
| `console.log` | 主程式輸出（出問題時最先看這個） |
| `observations.ndjson` | 每一幀的辨識結果 |
| `events_live.ndjson` | 局中事件，即時寫入 |
| `events.ndjson` | 局中事件的最終版（結束時寫） |
| `mjai.jsonl` | 實際送給 Mortal 的事件 |
| `mortal_replies.jsonl` | Mortal 的每一筆回覆 |
| `advice.ndjson` | 字幕列顯示過的每一筆建議 |
| `delivery.ndjson` | 每一筆事件送出／被擋下的紀錄 |
| `frames.mp4` + `video_index.csv` | 錄影（一場約 250 MB）與幀號對照 |
| `record_summary.txt` | 速度統計 |

啟動器本身的紀錄在 `runtime\agent_last.log`。

## 8. 設定（config.json）

用記事本打開修改，存檔後下次開始時生效。

| 設定 | 預設 | 說明 |
|---|---|---|
| `save_video` | `true` | 存錄影。不要的話改成 `false`（錄影是事後查錯用的，空間夠建議保留） |
| `show_preview` | `false` | 改成 `true` 會另開一個縮小的遊戲畫面視窗（除錯用） |
| `record_dir` | `"紀錄"` | 紀錄放哪裡，也可以寫完整路徑，例如 `"D:\\雀魂紀錄"`（反斜線寫兩個） |
| `window_title` | `"雀魂"` | 找遊戲視窗用的標題文字 |
| `web_url` | 雀魂網址 | 網頁版＋Chrome 開啟的網址 |
| `bar_width` | `1000` | 字幕列寬度（像素） |
| `bar_alpha` | `0.88` | 字幕列透明度（0.3–1.0） |
| `show_dots` | `true` | 開始時顯示手牌徽章（F9 隨時切換） |
| `show_second` | `true` | 開始時顯示次選（F7 隨時切換） |
| `hotkeys` | F8／F9／F7 | 快捷鍵（見第 4 節） |
| `mortal_weights_url` | `""` | Mortal 權重的公開下載網址（選填，見安裝說明） |
| `mortal` | `"docker"` | 不要改 |
| `launcher` | — | 啟動器記住的選擇（平台、同意說明、擷取權限），自動產生，不用手動改 |

## 9. 常見問題

**字幕一直顯示「找不到雀魂視窗」**
確認遊戲有開、沒有最小化。`app\window.json` 記著上次用的遊戲程式；換成網頁版或換電腦時，把它刪掉再開始，程式會重新找。

**字幕顯示「遊戲視窗不是 16:9」**
把遊戲視窗調成 16:9（或全螢幕），再按 [↻] 新的一場。

**字幕顯示 Docker 沒開**
打開 Docker Desktop，等「Engine running」，程式會自己再試。

**字幕顯示找不到 mortal 映像**
重新開啟 `雀魂AI助手.exe`，安裝精靈會建立映像。確認方法：命令提示字元輸入 `docker image ls`，清單裡有 `mortal` 就是好了。

**左邊顯示 CPU**
沒有可用的 NVIDIA 顯示卡（或驅動太舊），辨識會跟不上。更新 NVIDIA 驅動後，刪掉 `runtime\env.json` 再開啟 `雀魂AI助手.exe`，會重新安裝 GPU 版。

**每秒幀數很低（GPU 卻低於 5 fps）**
關掉其他吃顯示卡的程式（直播、錄影軟體）再試。

**字幕列不見了**
可能被拖到螢幕外。停止後重新開始，字幕列會回到螢幕上方正中間。

**程式異常結束**
啟動器會顯示「程式異常結束」。看 `runtime\agent_last.log` 與 `紀錄\<最新的資料夾>\console.log` 最後幾行。
