# MIA — 雀魂 AI 助手（Mahjong Intelligent Assistant）

即時讀取雀魂（Mahjong Soul）的遊戲畫面，用 4 顆 YOLO 模型辨識牌局，轉成 MJAI 事件交給麻將 AI **Mortal**，
再把建議顯示在遊戲畫面上方的字幕列與手牌上的數字徽章。

> 程式只「看」畫面，不會操作遊戲、不會幫你出牌，也不讀取或修改遊戲的記憶體與網路封包。
> 建議僅供參考，實際打哪張由玩家自己決定。

## 功能

- **支援 Steam／桌面版與網頁版**（Chrome、Edge 等），網頁版會自動從瀏覽器畫面切出遊戲區域。
- **四顆辨識模型**：局勢（宣告橫幅、摸入牌、手臂…）、牌河、手牌、鳴牌區，加上場況與寶牌讀取。
- **事件帳 + Mortal 守門器**：每個事件都依因果順序檢查欄位與 P0 手牌帳，確定沒問題才送給 Mortal；
  辨識有矛盾時暫停建議，並在下一次輪到你摸牌時**從畫面自動重新同步**。
- **字幕列**：顯示首選／次選；要按宣告鍵（吃碰槓、立直、和）時整條變金色。
- **手牌數字徽章**：在建議的那張牌正上方標「1」（首選）、「2」（次選），鳴牌時標出要拿出來的牌。
- **安裝精靈**：`雀魂AI助手.exe` 自動安裝 Python 與辨識套件、建立 Mortal 的 Docker 映像。
- **完整紀錄**：每一場都存下錄影、逐幀辨識結果、送給 Mortal 的事件與建議，可事後重播查錯。

## 快速開始

1. 在 GitHub 頁面按 **Code → Download ZIP**，解壓縮到任意資料夾（路徑盡量短，例如 `D:\MIA`）。
2. 到 **Releases** 下載 `mortal.pth`，放到 `app\Model\`（約 130 MB，見[安裝說明](docs/安裝說明.md#3-mortal-權重)）。
3. 安裝並開啟 **Docker Desktop**（見[安裝說明](docs/安裝說明.md#2-docker-desktop)）。
4. 雙擊 **`打包主程式.bat`**：自動準備 Python、產生 `雀魂AI助手.exe` 並開啟。
5. 照著 `雀魂AI助手.exe` 的畫面完成安裝 → 選平台 → 確認畫面 → 開始打牌。

之後每次使用只要雙擊 **`雀魂AI助手.exe`**。

## 系統需求

| 項目 | 需求 |
|---|---|
| 作業系統 | Windows 10 / 11（64 位元） |
| 顯示卡 | NVIDIA（強烈建議；沒有的話用 CPU 版，辨識會跟不上牌局） |
| 記憶體 | 16 GB 以上 |
| 硬碟 | 約 15 GB（Python 套件約 5 GB、Docker 映像約 6 GB） |
| 其他 | Docker Desktop（WSL 2）、第一次安裝需要網路 |

開發與測試環境：RTX 4060、Ryzen 5 5500GT、43.9 GB RAM、Windows 11 家用版。

## 實測結果（2026-11，RTX 4060）

| 指標 | 結果 |
|---|---|
| 畫面看到事件 → 送給 Mortal（中位數／P95） | 1,038 ms ／ 1,553 ms |
| Mortal 推論（中位數／P95） | 29.7 ms ／ 164.5 ms |
| 看到 P0 摸牌 → 字幕出現建議（中位數／P95） | 856 ms ／ 1,652 ms |
| 打牌牌面準確率（送給 Mortal 的事件，3 場對照牌譜） | 96.4 % |
| P0 摸牌牌面準確率 | 97.2 % |
| 摸切／手切判斷準確率 | 99.8 % |
| 輪到你摸牌時收到建議的比例（10 場） | 89.3 % |
| 建議與「用正確牌譜重跑 Mortal」首選一致率（141 個決策點） | 100 % |

## 資料夾結構

```
MIA/
├─ 打包主程式.bat          產生並開啟 雀魂AI助手.exe（第一次使用從這裡開始）
├─ 說明書.txt              離線版使用手冊
├─ config.json             設定（錄影、快捷鍵、字幕列外觀…）
├─ requirements_gpu.txt    辨識套件清單（GPU 版，版本鎖定）
├─ requirements_cpu.txt    辨識套件清單（CPU 版）
├─ launcher/launcher.py    雀魂AI助手.exe 的原始碼（安裝精靈、選平台、啟動）
├─ app/                    主程式
│  ├─ live_v7/             即時管線：判讀、事件帳、Mortal 守門器、字幕列
│  ├─ Model/               辨識模型權重（mortal.pth 另外下載）
│  ├─ Mortal/              Mortal 原始碼（建立 Docker 映像用）
│  └─ assets/              場況、風位的比對模板
├─ tools/                  重播、抽幀、重新辨識等除錯工具
└─ docs/                   文件與架構圖
```

第一次執行後會自動出現 `runtime\`（Python 環境）、`紀錄\`（每一場的紀錄）、`雀魂AI助手.exe`，這些都不會上傳到 git。
