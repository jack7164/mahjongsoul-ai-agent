雀魂 AI 助手(mahjongsoul ai agent)說明書
==========================================

讀雀魂的遊戲畫面 -> 辨識出牌局 -> 交給 Mortal(麻將 AI)-> 把建議顯示在螢幕最上方的字幕列。
程式只「看」畫面,不會操作遊戲,也不會幫你出牌。


★ 第一次使用
------------
  1) 安裝 Docker Desktop(見第 1 節),打開它。
  2) 到 GitHub 專案的 Releases 下載 mortal.pth,放到  app\Model\mortal.pth
  3) 雙擊「打包主程式.bat」:
       ・沒有 Python 的話自動下載(約 30 MB,放在 runtime\,不用另外裝 Anaconda)
       ・產生「雀魂AI助手.exe」並自動開啟
  4) 照著「雀魂AI助手.exe」的畫面做:
       1. 安裝    自動安裝 Python 辨識套件(約 3GB)、建立 Mortal 映像
       2. 說明    用途、運作方式、風險、需要的權限、免責聲明(同意後下次不再出現)
       3. 平台    Steam / 桌面版,或網頁版(Chrome 會用特殊模式開啟,結束時自動還原設定)
       4. 畫面確認 允許擷取視窗 -> 顯示程式實際看到的畫面,確認正確後開始
  之後每次使用:直接雙擊「雀魂AI助手.exe」。
  開始後字幕列出現在螢幕最上方,啟動器視窗會縮到工作列;按字幕列的 [停止] 結束。
  ・exe 只是啟動器,要放在這個資料夾裡(它會用到 app\、requirements_*.txt)。
  ・環境裝在 runtime\(約 5GB);啟動器的紀錄在 runtime\agent_last.log。
  ・更完整的說明在 docs\ 資料夾(安裝說明、使用說明、程式說明)。


資料夾內容
----------
  打包主程式.bat        第一次使用從這裡開始:產生並開啟 雀魂AI助手.exe
  雀魂AI助手.exe        主程式(執行打包主程式.bat 後才會出現)
  config.json           設定(要不要存錄影等等,見第 5 節)
  說明書.txt            這份文件
  requirements_*.txt    辨識套件清單(安裝時自動使用,不用動)
  launcher\             雀魂AI助手.exe 的原始碼
  app\                  辨識程式、辨識模型(app\Model\)、Mortal 原始碼(app\Mortal\)
  tools\                除錯工具(見第 6 節,平常用不到)
  docs\                 詳細文件與架構圖
  runtime\              自動安裝的 Python 環境(第一次執行後才會出現)
  紀錄\                 每次執行的紀錄(第一次執行後才會出現)


================================================================
1. 第一次安裝:Docker Desktop 與 Mortal 權重
================================================================
需求
  ・Windows 10 / 11(64 位元)
  ・NVIDIA 顯示卡(強烈建議)。沒有顯示卡也能裝,但辨識太慢、跟不上牌局。
  ・記憶體 16GB 以上、硬碟空間約 15GB(Python 套件約 5GB、Docker 映像約 6GB)

Python 環境不用自己裝:雀魂AI助手.exe 會自動判斷有沒有 NVIDIA 顯示卡,
裝 GPU 版或 CPU 版(版本鎖定 ultralytics 8.4.127、torch 2.5.1)。
  ★ 不要自己升級 ultralytics:不同版本對同一個模型的推論方式不一樣,
    辨識結果會改變(2026-11-03 實測過)。

Mortal 是在 Docker 裡面跑的(它需要 Linux 環境)。Docker Desktop 沒辦法用
程式自動安裝,要手動裝一次:

  1) 開啟 WSL2(Windows 的 Linux 子系統):
     在「開始」搜尋 PowerShell -> 右鍵「以系統管理員身分執行」-> 輸入
         wsl --install
     完成後重新開機。
  2) 安裝 Docker Desktop:
       https://docs.docker.com/desktop/setup/install/windows-install/
     安裝時勾選「Use WSL 2 instead of Hyper-V」(預設就是)。裝完重新開機。
  3) 打開 Docker Desktop,等左下角顯示「Engine running」(綠色)。
     第一次開會要求同意條款、可以略過登入。
     (建議在 Docker Desktop 的 Settings -> General 勾選「Start Docker Desktop when you sign in」,
       之後開機就會自動開。)
  4) Mortal 的權重檔放在:  app\Model\mortal.pth  (約 130MB)
     從 GitHub 專案的 Releases 下載。沒有的話安裝畫面的「Mortal 權重檔」會顯示「缺少」,
     放好後按「重新偵測」。
  5) Mortal 映像由雀魂AI助手.exe 自動建立:第一次要下載與編譯,約 10~30 分鐘(需要網路)。

  確認方法:在命令提示字元輸入  docker image ls  ,清單裡有 mortal 就是好了。


================================================================
2. 更新與解除安裝
================================================================
  更新:新版解壓縮後覆蓋到原本的資料夾(保留 runtime\、紀錄\、app\Model\mortal.pth、
        config.json)。啟動器有改的話再執行一次「打包主程式.bat」。
  解除安裝:刪掉整個資料夾;命令提示字元輸入  docker image rm mortal  刪掉映像。


================================================================
3. 每次使用
================================================================
  1) 打開 Docker Desktop(已設定開機自動開就不用)。
  2) 打開雀魂,視窗大小要是 16:9(例如 1920x1080、1600x900、1280x720),不要最小化。
     視窗被別的視窗蓋住沒關係,但不能最小化。
  3) 雙擊「雀魂AI助手.exe」,選平台、確認畫面後按開始。
     ・螢幕最上方會出現一條字幕列。用滑鼠按住字幕列的文字拖動,可以放到任何位置
       (建議放在遊戲畫面上方、不擋到牌的地方)。
  4) 開始打牌。程式會自己偵測到對局開始。

網頁版(瀏覽器打雀魂)
  ★ 在雀魂AI助手.exe 選「網頁版」+「Chrome(建議)」。它會:
      1. 檢查 Chrome 有沒有開著:開著的話請先全部關掉
         —— 要讓第 3 步的參數生效,Chrome 一定要重新開。
      2. 暫時改兩個 Chrome 設定:雀魂分頁不會被「記憶體節省模式」卸載、
         關掉「節能模式」。這段期間 Chrome 設定頁會顯示「由貴機構管理」,正常。
      3. 用特殊參數開 Chrome 直接進雀魂:視窗被別的視窗整個蓋住也照常更新畫面。
      4. 開主程式。
      5. 按字幕列 [停止] 結束時,第 2 步的設定自動還原成你原本的樣子。
         (Chrome 本身不會被關掉;第 3 步的參數只對這次開的 Chrome 有效,
           Chrome 關掉再正常打開就沒了)
    程式沒有正常結束的話第 5 步不會執行 -> 下次開啟雀魂AI助手.exe 時會自動先還原。
    想確認現在的狀態:Chrome 網址列輸入 chrome://policy
    雀魂網址在 config.json 的 "web_url"(預設 https://game.maj-soul.com/1/)。
  ・遊戲畫面寬度至少 1100 像素(最大化最穩)。視窗縮太小牌會讀錯,
    字幕列左邊會出現橘色「⚠ 畫面太小」,拉大就好。
  ・可以全螢幕(F11),也可以一般視窗/最大化;網頁縮放幾 % 都可以(建議 100%)。
    程式會自己在瀏覽器裡找出遊戲畫面(切掉分頁列、網址列、書籤列、兩旁的花紋)。
    要先進到牌桌畫面才找得到;主控台會印「🌐 … 找到遊戲畫面」。
  ・雀魂要是那個瀏覽器視窗「目前顯示的分頁」。
  ・瀏覽器不要縮到最小(最小化時 Windows 不給畫面,什麼設定都救不了)。
    選「其他瀏覽器」的話,也不要被別的視窗「整個」蓋住 ——
    Chrome 在完全看不到的時候會停止更新畫面。
  ・同時開著 Steam 版跟網頁版時,程式可能分不出要抓哪一個:只開一個就好。

字幕列
  左邊   GPU/CPU、每秒處理幾幀(GPU 正常約 8~15)、目前第幾局
  中間   字幕:
           白色      啟動中 / 載入辨識模型中…(約 10~30 秒)
           淺藍色    就緒,等待對局開始…     <- 準備好了,開局後會自動開始
           綠色      開始辨識(顯示 3 秒)、每一局開始時「東2局 開始」(2 秒)
           白色粗字  建議:打 北　次選:打 9s
           金色粗字  要你按宣告鍵的建議(吃/碰/槓/立直/和了),例如
                     建議:碰 5p(用 5p 5p)　次選:不鳴
                     建議:立直,打 2m　次選:不立直,打 2p
           淺藍色    本局結束:對家榮和(你放銃)　等待下一局…
                     -> 偵測到和了/流局。下一局開始會自動接上,不用按任何東西。
           橘色      辨識有誤,下次輪到你摸牌時自動重新同步
                     -> 程式算的「你的手牌」跟畫面對不上(例如讀錯一張牌)。
                        下次輪到你摸牌時,程式會照當下畫面重建這一局,建議自動恢復,
                        左邊局數旁會標「(已重新同步)」。不用按任何東西。
                     ・別家的牌讀錯、漏看一個動作:程式直接略過那一筆,建議照常,
                       不會出現這行字(只記在 console.log)。
                     ・重新同步後 Mortal 不知道別家每張牌確切是哪一巡打的,
                       安全牌判斷可能稍微不準;你的手牌、寶牌、牌河都是對的。
           紅色      錯誤(Docker 沒開、找不到遊戲視窗…),照字幕說的處理就好,
                     程式會自己再試
  右邊   三個圖示按鈕:[－]縮小  [↻]新的一場  [■]停止
  底色   要按宣告鍵的建議(吃碰槓立直和)整條變金色;辨識有誤變橘色

  建議什麼時候消失:你做了動作(打牌、鳴牌…)之後、或換局時。「不鳴」顯示幾秒後自動消失。

手牌上的數字徽章(2026-11-11 起取代紅點/藍點)
  綠色「1」     建議打的那張牌(要打剛摸到的那張時,就在摸入牌上)
  深色「2」     次選那張(次選是「不鳴」「立直」之類時沒有)
  金色「碰/吃/槓」 建議鳴牌時,標在要拿出來的那幾張
  徽章不會擋到滑鼠,可以直接點下面的牌。遊戲視窗移動後下一瞬間會跟上。
  宣告類的建議:
    吃/碰/槓  金色徽章標在「要拿出來的那幾張」,字幕寫要吃/碰哪一張;遊戲跳出按鈕時按對應的鍵
    立直      「1」標在「立直要打的那張」;先按遊戲的「立直」,再點「1」那張
    和了      只有字幕(金色「建議:和了!」),按遊戲的「和」/「自摸」
    不鳴      只有字幕,幾秒後自動消失;按遊戲的「跳過」

快捷鍵(遊戲視窗在前面也有效)
  F8   字幕列 縮小/展開(縮小時上方剩一個小小的「● AI ▾」,點它也會展開;
       字幕列右邊的「－」按鈕也可以縮小。小視窗的圓點顏色跟字幕一樣:
       金色=建議宣告(吃碰槓立直和)、白色=有打牌建議、橘色=辨識有誤、淺藍=等待中)
       要宣告時小視窗直接寫動作,例如「● 碰! ▾」。
  F9   手牌徽章 顯示/隱藏
  F7   次選 顯示/隱藏(提示列的「次選 …」跟「2」徽章一起)
  想換鍵:改 config.json 的 "hotkeys"(F1~F12,可加 Ctrl+ / Alt+ / Shift+,
          例如 "Ctrl+Alt+F8")。註冊失敗(被別的程式佔用)時 console.log 會寫。

★ 要結束一律按字幕列的 [停止]。

★ 程式只能「建議」,實際打哪張還是你自己決定。辨識偶爾會錯,建議看起來怪怪的時候以自己為準。


================================================================
4. 一場打完之後(重要)
================================================================
「一場」= 整個東風戰(打到東4局結束)或半莊戰(打到南4局結束)。
一場裡面的換局(和了、自摸、流局)程式會自己處理,不用按任何東西。

一場結束後,開下一場之前,請擇一:
  ・按字幕列的 [新的一場]:存好這一場的紀錄、開新的紀錄資料夾、重新載入(約 10~30 秒),
    看到「就緒」再開下一場。
  ・按 [停止] 結束,啟動器會顯示「已結束」,按「再開一場」繼續。

★ 不要不按就直接連打下一場:Mortal 的座位編號是整場固定的,接著打下一場可能會錯位。

[停止] 會先把紀錄寫完、關掉 Mortal,再關閉程式,需要幾秒鐘。
不要直接關掉程式視窗:紀錄檔可能來不及寫完。

5. 紀錄與設定
================================================================
紀錄:每按一次啟動(或 [新的一場])一個資料夾  紀錄\<日期_時間>\
  console.log              主控台輸出(出問題時最先看這個)
  observations.ndjson      每一幀的辨識結果
  events_live.ndjson       局中事件,即時寫入(打牌、摸牌、鳴牌、和了…)
  events.ndjson            局中事件的最終版(結束時寫)
  mjai.jsonl               實際送給 Mortal 的事件
  mortal_replies.jsonl     Mortal 的每一筆回覆
  advice.ndjson            字幕列顯示過的每一筆建議
  delivery.ndjson          每一筆事件送出 / 被擋下的紀錄
  frames.mp4 + video_index.csv   錄影(一場約 250MB)
  record_summary.txt       速度統計

設定:用記事本打開 config.json 修改,改完存檔,下次啟動生效。
  "save_video": true       存錄影。不要存的話改成  false
                           (錄影是之後查錯、拿新模型重新辨識用的;空間夠的話建議保留)
  "show_preview": false    改成 true 會另外開一個縮小的遊戲畫面視窗(看程式抓到什麼,除錯用)
  "record_dir": "紀錄"     紀錄放哪裡(也可以寫完整路徑,例如 "D:\\雀魂紀錄",反斜線要寫兩個)
  "window_title": "雀魂"   找遊戲視窗用的標題文字
  "web_url": "https://game.maj-soul.com/1/"   網頁版+Chrome 開的雀魂網址
  "bar_width": 1000        字幕列寬度(像素)
  "bar_alpha": 0.88        字幕列透明度(0.3 ~ 1.0)
  "show_dots": true        啟動時要不要顯示手牌徽章(F9 隨時切換)
  "launcher": {...}        主程式記住的選擇(平台、是否同意說明、擷取權限),不用手動改
  "show_second": true      啟動時要不要顯示次選(F7 隨時切換)
  "hotkeys": {...}         快捷鍵(見第 3 節)
  "mortal_weights_url": "" Mortal 權重的公開下載網址(選填;有填的話缺權重時自動下載)
  "mortal": "docker"       不要動

6. 除錯工具(tools\)
================================================================
平常用不到。要用的話開「命令提示字元」,到這個資料夾:
    cd /d "<這個資料夾>"
用 runtime\env.json 裡 "python" 那一行的 python.exe 執行(下面寫成 python):
  python tools\replay.py 紀錄\<資料夾>\observations.ndjson
        用紀錄重跑一次判斷,印出每一局有沒有被擋下、為什麼(replay_summary.txt)
  python tools\check_sheet.py 紀錄\<資料夾>\events.ndjson
        印出對照表:每一家每一張打牌、摸切/手切,方便跟牌譜對照
  python tools\dump_frames.py 紀錄\<資料夾> 600-700:5
        從錄影抽出指定幀存成圖片(紀錄\<資料夾>\snap\)
  python tools\dump_dora.py 紀錄\<資料夾>
        檢查寶牌指示牌的讀法(紀錄\<資料夾>\dora\sheet.png)
  python tools\reread_region.py 紀錄\<資料夾> --river <牌河權重> --tag 新牌河
        用錄影換一個模型重新辨識(比較新舊模型用;需要錄影)
  python tools\reread_ui.py 紀錄\<資料夾>
        用錄影重算場況(局數、點數、寶牌)
  python tools\test_overflow.py 紀錄\<資料夾>
        測試「牌河超過 18 張」讀不讀得到:把錄影裡的牌貼成第 19~21 張再讀,
        印出每一張讀對沒有,圖在 紀錄\<資料夾>\overflow_test\
  python tools\test_overflow.py --live
        實戰真的超過 18 張時:抓現在的遊戲畫面讀一次,存成圖(可以跟主程式同時跑)

7. 常見問題
================================================================
・字幕一直顯示「找不到雀魂視窗」
    確認遊戲有開、沒有最小化。app\window.json 記著上次用的遊戲程式
    (Jantama_MahjongSoul.exe,也就是 Steam / 桌面版)。用瀏覽器版的話,
    把 app\window.json 刪掉再啟動,程式會重新找、找到後重新記住。
    還是找不到:用 runtime\env.json 記錄的 python.exe,到 app\ 執行
        python 1_capture.py --list
    找到遊戲視窗那一行的 hwnd,再執行  python 1_capture.py --hwnd <數字>  讓它記住。
・字幕顯示「遊戲視窗不是 16:9」:把遊戲視窗調成 16:9(或全螢幕),再按 [新的一場]。
・字幕顯示 Docker 沒開:打開 Docker Desktop,等「Engine running」,程式會自己再試。
・字幕顯示找不到 mortal 映像:重新開啟雀魂AI助手.exe,安裝畫面會建立映像。
・左邊顯示 CPU:這台電腦沒有可用的 NVIDIA 顯示卡(或驅動太舊),辨識會跟不上。
  請更新 NVIDIA 驅動程式,刪掉 runtime\env.json 後重新開啟雀魂AI助手.exe(會重裝 GPU 版)。
・每秒幀數很低(GPU 卻低於 5):關掉其他吃顯示卡的程式(直播、錄影軟體)再試。
・字幕列不見了:它在螢幕最上方;可能被拖到螢幕外,按 [停止] 後重新開始會回到正中間。
・出現錯誤視窗或程式自己關掉:看  runtime\agent_last.log  和  紀錄\<最新的資料夾>\console.log  最後幾行。

8. 目前使用的模型(app\Model\)
================================================================
  region_model_best.pt              局勢:摸入牌、手臂、吃碰槓立直和了的橫幅、手牌區、鳴牌區
  river_model_best.pt (+.infer.json)  牌河(2026-11-03 新版)
  hand_model_best.pt                手牌(也用來讀寶牌指示牌)
